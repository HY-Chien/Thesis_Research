# Gate Signal Replay Analysis

Signal-agnostic comparison of retrieval-gate signals, replayed offline from existing traces (`scripts/replay_gate_signal_analysis.py`). Labels come from the 3way never/always endpoints; all signal values for a dataset are read from a single trace so the cross-signal comparison is fair.

**Caveats:** (1) question-level simulation (retrieve for all steps or none), while the deployed gate is per-step; (2) step-2+ signal values are conditioned on the source trace's retrieval branch — the `AUROC(need) s1` column uses only step-1 signals, which are chain-independent, as a robustness check; (3) datasets without a finished dual sweep only cover the entropy-family signals (rerun after the MuSiQue/PopQA sweeps finish).
