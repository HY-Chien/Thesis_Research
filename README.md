# SEEK: Self-certainty Evaluated Evidence-gated Knowledge-retrieval

SEEK is an adaptive retrieval-augmented generation method for
knowledge-intensive question answering. It uses Tail Leakage to decide when
retrieval is needed and a deterministic verifier to select the final answer.

For a basic code review, complete Sections 2 and 3. Continue with Sections 4–6
only when retraining the decomposer or running fresh model inference.

## 5. Train the Decomposer

The file
`configs/llama3_8b_decomposer_lora_3ds.yaml` is a configuration input, not a
command. Do not execute it with `./configs/...yaml`.

First, accept the
[Meta-Llama-3-8B-Instruct license](https://huggingface.co/meta-llama/Meta-Llama-3-8B-Instruct)
and authenticate:

```bash
hf auth login
nvidia-smi
```

Install the pinned LLaMA-Factory revision:

```bash
export LLAMA_FACTORY_DIR="$(cd ../.. && pwd)/LLaMA-Factory"

if [ ! -d "$LLAMA_FACTORY_DIR/.git" ]; then
  git clone https://github.com/hiyouga/LLaMA-Factory.git "$LLAMA_FACTORY_DIR"
fi

git -C "$LLAMA_FACTORY_DIR" checkout 7e20db5735443861fad91766614b3415ff8966a4
python -m pip install -e "$LLAMA_FACTORY_DIR"
python -m pip check
```

Check the environment, dataset paths, and YAML configuration without starting
training:

```bash
export SEEK_DATA_DIR=/tmp/SEEK-decomposer-12k
bash scripts/train_decomposer.sh --check-only
```

The last line should be `Training preflight passed.`. Then start the full
three-epoch training run:

```bash
bash scripts/train_decomposer.sh
```

- Input: `$SEEK_DATA_DIR/data/{musique,twowiki,popqa}/train.json`
- Configuration: `configs/llama3_8b_decomposer_lora_3ds.yaml`
- Output:
  `$LLAMA_FACTORY_DIR/saves/seek/llama3-8b-decomposer-musique-2wiki-popqa/`

The wrapper uses GPU 0 by default and automatically copies and registers the
three datasets before passing the YAML to LLaMA-Factory. To use GPU 1:

```bash
CUDA_VISIBLE_DEVICES=1 bash scripts/train_decomposer.sh
```

## 6. Run the Thesis Main Method

Fresh main-method inference requires:

- the trained decomposer adapter from Section 5;
- access to `meta-llama/Meta-Llama-3-8B-Instruct`;
- an Elasticsearch 7.10.2 server containing the 21M-passage index named
  `wiki`.

The Wikipedia index is not stored in Git. Before running, verify that it is
available:

```bash
curl -s http://localhost:9200/_cluster/health
curl -s http://localhost:9200/_cat/indices/wiki?v
```

Run the four thesis datasets:

```bash
export LLAMA_FACTORY_DIR="${LLAMA_FACTORY_DIR:-$(cd ../.. && pwd)/LLaMA-Factory}"
export BASE_MODEL=meta-llama/Meta-Llama-3-8B-Instruct
export SEEK_ADAPTER="$LLAMA_FACTORY_DIR/saves/seek/llama3-8b-decomposer-musique-2wiki-popqa"
export SEEK_ES_HOST=localhost
export SEEK_ES_PORT=9200

for DATASET in hotpotqa 2wikimultihopqa musique popqa; do
  CUDA_VISIBLE_DEVICES=0 python scripts/run_seek_dual.py \
    --base "$BASE_MODEL" \
    --adapter "$SEEK_ADAPTER" \
    --dev "datasets/evaluation/${DATASET}.jsonl" \
    --mode C \
    --signal tail_leakage \
    --tau 0.002305 \
    --corpus wiki \
    --es-host "$SEEK_ES_HOST" \
    --es-port "$SEEK_ES_PORT" \
    --top-k 8 \
    --title-mode pathaware \
    --direct-context-union \
    --no-evidence \
    --direct-confidence-tau 0.0005 \
    --decomp-post-confidence-tau 0.0158 \
    --typeaware-fallback \
    --fallback auto \
    --out "results/generated/seek_${DATASET}.jsonl"
done
```

- Input: `datasets/evaluation/{hotpotqa,2wikimultihopqa,musique,popqa}.jsonl`
- Output: `results/generated/seek_{dataset}.jsonl`

Fresh generation is not expected to be bit-identical to the saved traces.
