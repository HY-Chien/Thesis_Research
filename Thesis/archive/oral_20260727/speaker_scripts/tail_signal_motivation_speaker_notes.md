# Same Top Prediction, Different Confidence — 口頭講稿

這一頁先不要看公式，只看一個直觀例子。

模型每次生成 token 時，會替完整 vocabulary 裡的每個 token 分配機率，再由高到低排序。這裡的 **top-5**，就是當下機率最高的五個 token，不是 vocabulary 最後五個；而且每生成一個新 token，top-5 都會重新計算。

我們把這五個 token 的機率加起來，記成 $m_5$。排名第六名以後的所有 token 合起來就是 tail，所以 tail mass 等於 $1-m_5$。

接著看左右兩個示意例子。兩邊第一名都是 `PO`，機率也完全一樣，都是 0.60。如果只看 top-1，會覺得模型的信心沒有差別。

左邊除了 `PO` 之外，機率主要仍留在 `po`、`Po` 等相近形式裡。這些可能只是大小寫、拼法或 tokenization 的差異。top-5 合計保留 97%，只有 3% 跑到後面的 tail，所以我們把它視為比較高信心。

右邊的 `PO` 仍然是 0.60，看起來一樣很高；但 top-5 合計只剩 78%，有 22% 分散到第六名以後。也就是模型表面上有一個強的第一名，背後卻同時保留很多其他可能性，因此整體信心比較低。

所以這張投影片真正要傳達的是：**不要只問第一名有多高，而要問主要候選集合之外還累積了多少機率。**

最後，為什麼是 5？五不是公式推導出的常數，而是驗證後選擇的 cutoff。$k=2$ 的 macro AUROC 是 0.741，$k=5$ 是 0.749，$k=10$ 是 0.750。$k=5$ 和 $k=10$ 已經在同一個效能平台，因此選擇較小的 $k=5$；如果更換 backbone 或 tokenizer，這個 $k$ 仍然應該重新驗證。

一句話收尾：**相同的 top-1 probability，不代表相同的 confidence；真正的差別可能藏在 tail mass。**
